Скорость, выбранная в первый момент после открытия страницы, больше не теряется.

Расширение запоминает скорость для каждого фильма отдельно (если эта настройка включена). Если скорость нажали раньше, чем страница успела сообщить, какой фильм открыт, выбор молча пропадал — теперь он сохраняется, как только фильм опознан. На HDRezka это редкий случай, но общий код у обоих расширений один, а на YouTube-близнеце из-за этого память по каналам почти не работала.

A speed picked in the first moments after the page opens is no longer lost.

The extension remembers a speed per film (when that setting is on). If the speed was pressed before the page had said which film is open, the choice was silently dropped — now it is stored as soon as the film is identified. On HDRezka this is a rare case, but both extensions share the same core, and on the YouTube twin it made per-channel memory almost useless.
