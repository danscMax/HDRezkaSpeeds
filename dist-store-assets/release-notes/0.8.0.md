Один клик по кнопке скорости теперь меняет скорость только текущего просмотра — и ничего больше.

Раньше, если была включена память по фильмам, тот же клик заодно записывал скорость за фильмом. Теперь это две разные вещи: скорость для фильма сохраняется отдельной кнопкой на панели, рядом с закладкой «по умолчанию везде». Кнопка горит, пока у фильма есть своя скорость; нажать ещё раз — снять. Она же включает саму функцию.

Исправлена панель: одна лишняя кнопка скорости отправляла ползунок и шестерёнку на вторую строку. Теперь переносятся сами кнопки скорости, а ползунок и значки остаются на своих местах.

Во вкладке «Диагностика» появилась строка о памяти скорости: какой фильм опознан, какая скорость для него сохранена, какая стоит по умолчанию и какая играет сейчас.

A single click on a speed button now changes the speed of the current playback only — and nothing else.

Previously, with per-title memory enabled, the same click also stored the speed for the title. These are two separate things now: saving a speed for a title has its own button on the panel, next to the "default everywhere" bookmark. It stays lit while the title has its own speed; press again to clear. It also switches the feature on.

The panel is fixed too: one extra speed button used to push the slider and the gear onto a second line. Now the speed buttons themselves wrap and the slider and icons keep their place.

The Diagnostics tab gained a line about the speed memory: which title was recognised, the speed saved for it, the default, and what is playing right now.
