Обновления снова доходят до Firefox на телефонах и планшетах.

Начиная с версии 0.6.2 сборки уходили в магазин без пометки о совместимости с Android, поэтому мобильный Firefox не предлагал обновиться и установки застряли на старой версии. Пометка вернулась и теперь ставится автоматически при каждой сборке. Ничего, кроме этого, в расширении не изменилось.

---

Updates reach Firefox on phones and tablets again.

From version 0.6.2 on, the builds went to the store without the Android compatibility flag, so mobile Firefox never offered an update and installs stayed on an old version. The flag is back and is now set automatically on every build. Nothing else in the extension changed.
